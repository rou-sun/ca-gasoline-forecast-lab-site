# California Gasoline Forecast Lab — Website

Public static dashboard for the California Gasoline Forecast Lab.

Live dashboard: https://rou-sun.github.io/ca-gasoline-forecast-lab-site/

This repository contains the compiled interactive dashboard and the data snapshot needed to display it. The analytical code and notebooks are maintained in the separate private project repository.

To update, replace the files with the verified contents of `app/dist` from the project, retaining `.nojekyll`, then push to `main`. GitHub Pages deploys automatically.

The included data snapshot was supplied for the course project. Original-source values and publication vintages remain unverified. Model outputs are exploratory, and nominal prediction intervals under-cover the evaluated test sample.
